# Screenshots checklist — How Far Can You Hit It?

Take these from the built native app once it runs on a device or simulator.
Do NOT use the web prototype for store screenshots (per AppStore/listing.md).

## Size (one iPhone set is enough)
- iPhone 6.9" portrait: 1320 × 2868 (also accepted: 1290 × 2796, 1260 × 2736).
  App Store Connect scales this down for smaller iPhones. A 6.5" set
  (1284 × 2778 / 1242 × 2688) is the fallback if no 6.9" set is provided.
- 1–10 screenshots per device size, per language. First 2–3 show in search
  results without tapping through — put the strongest shots first.
- Format: PNG or JPEG, RGB, no alpha channel / no transparency.
- If the app is submitted as iPad-compatible too, add a 13" iPad set
  (2064 × 2752 portrait). If iPhone-only, no iPad set is needed.
- Every screen shown must actually exist in the submitted build.

## Shot order (6 shots)
- Metadata rule (verified 2026-10-28 against Apple's official guidelines):
  store screenshots and previews must be suitable for all audiences, so
  no shot may show a roast / small-hit saying — hype lines and neutral
  result cards only.
1. Gameplay mid-swing — yellow snowball, mountains-only background, a big hit.
2. Character picker — all five sluggers with signature bats visible.
3. Season picker — Fall (pumpkins) / Christmas (Christmas Trees) / Normal (baseball cards).
4. Result card — "It flew X pumpkins!" with a hype saying (big hit).
5. Build-a-Slugger — a custom cartoon slugger (small body, large goofy head).
6. Leaderboard — local/global board (only once Game Center is live; until then,
   use the local leaderboard screen and do not imply a global board exists).
